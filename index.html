Setup

Run Mosaic locally

Docker for Postgres with pgvector, Node for the API and client. OpenAI is required for embeddings, chat, and learn. Firecrawl and Cloudinary are needed for websites and PDF uploads.

Copy the example env and fill real values. Do not commit .env.

cd server
cp .env.example .env
# Set POSTGRES_PASSWORD, DATABASE_URL, JWT_SECRET
# OPENAI_API_KEY (required)
# FIRECRAWL_API_KEY (websites)
# CLOUDINARY_* (PDF uploads)
# CLIENT_ORIGIN=http://localhost:3000

Keep DATABASE_URL matched to POSTGRES_USER, POSTGRES_PASSWORD, and POSTGRES_DB.

Start Postgres, install server deps, apply migrations.

cd server
docker compose up -d
npm install
npx prisma migrate dev

Compose requires POSTGRES_PASSWORD and publishes on 127.0.0.1:5432 by default (POSTGRES_BIND). For production, use a strong password and attach the API to the mosaic-net Docker network instead of opening the port publicly.

Start the API, then Inngest in a second terminal after the API is up.

# terminal 1
cd server
npm run dev

# terminal 2
cd server
npm run inngest:dev
# http://localhost:9090/api/inngest
# Inngest UI: http://localhost:8288

INNGEST_EVENT_KEY and INNGEST_SIGNING_KEY are required only when the API talks to Inngest Cloud in production.

Start the Next.js app. / redirects to /mosaic.

cd client
npm install
npm run dev
# http://localhost:3000

# client/.env.local if needed:
# NEXT_PUBLIC_API_BASE_URL=http://localhost:9090

Only the public API origin belongs in NEXT_PUBLIC_*. Keep JWT, OpenAI, Cloudinary, and Firecrawl on the server.
